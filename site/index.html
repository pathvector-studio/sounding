Sounding — where the discussion stands

追いかける議論が今どこまで来たかを、毎朝のダイジェストで確かめる。セルフホスト型、まずはネットワークエンジニア向け。

Sounding とは

フォローしている IETF メーリングリストのスレッドごとに、次の 4 点をまとめて届けます。

  • 何が争点か
  • 合意はどこまで進んだか
  • 何が未決着か
  • 前回から何が動いたか

RSS / Atom の記事も同じダイジェストに入ります。すべてを見せるのではなく、あなたの興味プロファイルに合うものだけを選びます。自分のマシンで動かし、LLM は自分のキーを使います。

名前の由来

sounding は「測深」、つまり水深を測って自分の位置を確かめることです（taking soundings）。もうひとつ、sound out は「意見や合意の度合いを探る」という意味の句動詞です。膨大な一次情報の海で議論の現在地を測り、IETF の合意形成の温度を探る。その両方を一語で表す名前として選びました。

インストール

Docker Compose が必要です。

curl -sSL https://sounding.pathvector.dev/install.sh | bash

実行前に中身を読めます：https://sounding.pathvector.dev/install.sh、またはリポジトリの install.sh。

何がどこに送られるか

  • 出力は要約と出典リンクだけです。メッセージや記事の本文は再配布せず、取得した本文も保持期間を過ぎたら削除します。
  • LLM は自分のキーを持ち込みます（Anthropic、または OpenAI 互換）。既定は none で、キーを入れるまでマシンの外には何も送りません。
  • LLM に渡す前に、メールアドレスは伏せます。
  • 開き方は選べます：このマシンだけ、パスワード付きで LAN に、Tailscale、Cloudflare Tunnel + Access。

現状

初期段階（MVP）です。情報源は今のところ IETF メーリングリストと RSS / Atom です。
